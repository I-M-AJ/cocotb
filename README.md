# cocotb

This repository contains these project folders:

- `Coco_Questasim`: a counter and cocotb test for QuestaSim.
- [`Coco_VCS`](Coco_VCS/README.md): the same counter test for VCS, with Python 3.11 virtual environment setup, optional Verdi waveforms and an Icarus fallback.
- `Python4RTLVerification`: Python and RTL verification examples.

Clone the repository with:

```bash
git clone https://github.com/I-M-AJ/cocotb.git
```
